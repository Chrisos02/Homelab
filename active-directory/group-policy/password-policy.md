# Password Policy

## Purpose

Enforce stronger authentication requirements for the domain.

## Configuration

- Password history: 5 passwords remembered
- Maximum password age: 90 days
- Minimum password age: 1 day
- Minimum password length: 10 characters
- Complexity requirements: Enabled
- Store passwords using reversible encryption: Disabled

## Note

In a production environment, domain password policy is normally configured in the Default Domain Policy or with Fine-Grained Password Policies.
